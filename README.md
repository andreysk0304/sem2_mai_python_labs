## Что есть в проекте

Это небольшая платформа обработки задач, собранная по лабораторным работам курса.

- источники задач работают через единый контракт `TaskSourceProtocol`;
- модель `Task` валидирует состояние через дескрипторы и `@property`;
- `TaskQueue` поддерживает ленивую фильтрацию, повторный обход и потоковую обработку задач.
- `AsyncTaskQueue` и `AsyncTaskExecutor` обеспечивают асинхронную обработку задач;
- обработчики описаны через `AsyncHandlerProtocol`;
- ошибки обработки централизованно логируются в executor и сохраняются в `executor.errors`.

## Использование

### Тесты

Для запуска локально:

Установка зависимостей:
```bash 
pip install -r requirements.txt
```

Запуск тестов:
```bash
pytest tests/ -v
```

Запуск тестов с покрытием:
```bash
pytest tests/ -v --cov=task_platform --cov-report=term-missing
```

Текущее покрытие тестами: `94%`.

API для тестов поднимать не нужно: работа с ним замокана или использует локальные клиенты.

### Демо запуск

```bash
uvicorn task_platform.api.main:app --reload --port 8000
python3 run_demo.py
```

Сначала запускается API, затем демонстрационный сценарий. Демо показывает:

- чтение задач из нескольких источников;
- повторный обход `TaskQueue`;
- загрузку задач в `AsyncTaskQueue`;
- асинхронную обработку через `AsyncTaskExecutor`.

**Docker**

Одной командой поднять API и запустить демо (API остаётся работать, демо выполнится один раз после готовности API):

```bash
docker compose up
```

Только API (в фоне — `docker compose up -d api`):

```bash
docker compose up api
```

Только один прогон демо (API должен быть уже запущен):

```bash
docker compose run --rm demo
```
